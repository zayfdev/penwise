# Gate record: M2 editing engine

Branch `m2-editing`. Verdict: **PASS after fixes**.

## Scope

`penwise-core` item model (stroke/erase/shape/fill/text, layers, layerset, affine transforms, trims), `Scene` with rstar
index and derived geometry, `Edit`/`ItemPatch` (absolute LWW fields) with invert, hit test, lasso, selection transforms,
stroke + precise erasers (split in the sample domain, masks for stamp strokes and shapes, polygon cut for fills),
fill bucket (fixed grid, growing window, gap closing, marching squares, RDP, i_overlay cleanup), shape geometry with
handles/resize/constrain, undo/redo with gesture grouping, and versioned item/edit codecs.

wasm, PNG goldens, size check (all files ≤300 lines), `cargo deny`.
