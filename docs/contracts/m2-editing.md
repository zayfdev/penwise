# M2 contract: `penwise-core` editing engine

Status: committed contract for the M2 fan-out (PLAN "Phase loop" step 2, phase map row "M2 editing engine").
Implementers code against it and never change it; contract changes go back to the orchestrator. Sources:
`PLAN.md` ("Data model", "Brushes & tools", "Sync protocol"), `docs/research/editing-algorithms.md` (its
recommendations are adopted unless a decision below overrides them), `docs/research/core-determinism.md`,
`docs/contracts/m1-core.md` (M1 types are reused unchanged).

## Rules for every slice

- Edit only the files your slice owns (table below). `lib.rs`, `Cargo.toml`, the workspace `Cargo.toml`,
  `codec/mod.rs` and this doc are contract-owned. Need a new dependency, module, pub item or a signature change?
  Ask the orchestrator. M1 files are out of scope: M2 uses only M1's public API.
- **Frozen:** every `pub` item (names, fields, signatures, documented behaviour) and every `const` that defines a
  stored format (kind/field/layer/shape/arrow byte tags, `SampleParam::FRAC_BITS`, `CUT_BISECTION_STEPS`, blob
  layouts and magics `PWIT`/`PWED`).
- **Slice-internal:** private and `pub(crate)` items in your own files (all of `fill/` below `fill/mod.rs`,
  `item/index.rs`, the private fields of `Scene` and `UndoStack`). Add, reshape or delete them freely.
- Each file starts with `//! Owner: slice <x>`; replace each `todo!()` with the documented behaviour.
- Tests: sibling `tests.rs` (`#[cfg(test)] mod tests;` at the end of your own file) or
  `crates/penwise-core/tests/m2_<slice>.rs`. Test behaviour (outputs, round trips, convergence), not internals.
- AGENTS.md limits: ≤ 300 lines per source file (hard 500), ≤ 80 lines per fn, ≤ 7 params; no
  `unwrap`/`expect`/`panic!` outside tests; `thiserror` errors; no I/O, clocks, logging.
- Stub allow-list: each **new module root** (`item/mod.rs`, `edit/mod.rs`, `shape/mod.rs`, `fill/mod.rs`,
  `codec/item.rs`, `codec/edit.rs`) carries `#![allow(clippy::todo, …, reason = "M2 contract stubs")]`. The slice
  that owns the root removes it when its last stub lands (`item/` and `edit/` roots: slice a, after b and e have
  landed; the orchestrator does it if a finishes first). Finished code must be clean without it.
- Do not run gates mid-flight; the orchestrator runs `cargo fmt` and `just check` once all slices land.

## Decisions fixed by the contract

| Topic | Decision |
|---|---|
| Item | `Item { id: ItemId, layer, z: i64, transform: Affine, kind: ItemKind }`; kinds Stroke, Erase, Shape, Fill, Text |
| Ids | `ItemId([u8; 16])`, ULID bytes generated by the caller; core asks an `IdSource` for new ids, in a documented order |
| z | plain `i64`, new items `scene.next_z() = top_z + Z_STEP (2¹⁶)`; ties by id. Not a fractional index |
| Order | Queries return `(z, id)` ascending. Paint order is `(band, z, id)` with bands Fill < Multiply < Normal; "topmost" = largest `RenderKey` |
| Layers | visibility filter only (`LayerSet` on every query), not paint order |
| Transform | every item has a 2×3 `Affine` (f32 stored, f64 composed, `libm` angles). Strokes: samples mapped, width × `sqrt(|det|)`. Shapes: flattened in local space, mapped, stroked in page space at the brush's own width (width applied after transform) |
| Edits | `Edit::{Add(Item), Delete(ItemId), Update { id, patch: ItemPatch }}`; patches carry **absolute** values per `Field` (13 LWW registers); delete = tombstone |
| Outline-stroke precise erase | split in the raw-sample domain into pieces with `Trim` (research §1, option A) |
| Concurrent splits | pieces carry the whole-origin visible set of their split; the scene renders each family member over `own ∩ ⋂ others' sets`, so erased ink never reappears |
| Stamp strokes and shapes | precise erase adds one `Erase` mask item per (gesture call, target), path in the target's local frame; fully masked targets are deleted instead |
| Fills | precise erase cuts the polygon (fill stays vector; `Update { polygons, transform: IDENTITY }`), no mask |
| Undo | per (device, page) `UndoStack`; one gesture = one step; undo/redo emit new edits; only own edits; fields changed by others since (value no longer bitwise ours) are skipped |
| Spatial index | `rstar` R*-tree per page; hits sorted by `(z, id)` before use |
| Booleans | `i_overlay` integer API only, on the 1/16 px grid (fill cleanup, fill cut) |
| Fill bucket | fixed `FILL_CELL = 1 px`, windows 512² → 4096² cells, EDT closing, marching squares, RDP, `i_overlay` cleanup; open region → `FillError::OpenRegion` |
| Codec | item blob `PWIT` v1 and edit blob `PWED` v1, hand-written like M1, FNV-1a 64 trailer; bodies embeddable by `penwise-proto` |
| Dependencies | `rstar 0.13.0` (MIT OR Apache-2.0, MSRV 1.85); `i_overlay 9.1.0` (MIT OR Apache-2.0, MSRV 1.88, `default-features = false`, deps `i_float 5`, `i_shape 5`, `i_tree 0.20`, `i_key_sort 0.12`, all MIT) |

## Data flow

```
App / agent input ──► tool fn (&Scene, input) ──► Vec<Edit> ──► UndoStack::apply_local(&mut Scene, edits)  (local)
                                                         │                       └─► Scene::apply each edit
                                                         └─► penwise-proto (M3): op envelope {op id, device, HLC, seq}
                                                                                 └─► codec::edit (PWED body)
Remote / agent ops ──► penwise-proto LWW ──► Scene::apply (never recorded in the local UndoStack)
Undo/redo ──► UndoStack::undo/redo(&Scene) ──► Vec<Edit> ──► Scene::apply_all + send (not re-recorded)

Scene::apply ─► Item::validate ─► tombstones / order (band, z, id) / rstar index / families / masks
            └─► Item::derive_geometry (cached ItemGeometry):
                  Stroke ─ StrokeItem::{build_geometry, centreline} over Scene::visible_ranges   (b)
                  Erase  ─ EraseItem::page_mask under the target transform                        (b)
                  Shape  ─ shape::shape_geometry ─ path ─ outline::stroke_path (StrokeBuilder)    (d)
                  Fill   ─ Polygon::mapped                                                         (c)
                  Text   ─ box corners                                                             (a)
Tools: hit::hit_test/topmost, lasso::lasso, transform::*, select::*, erase_strokes, erase_precise,
       fill::fill_at, shape::resize::*  (all read cached geometry; none mutate the scene)
```

Typical gestures (each = one undo step): stroke → `Add(stroke)`; precise erase → `Delete` + piece `Add`s,
mask `Add`s, fill `Update`s; lasso + move → one `Update { transform }` per item at pen-up; fill tap →
`Add(fill)` or `Update { paint }`; shape create → `Add(shape)`; handle drag → `Update { shape_size, transform }`.

## Invariants

1. **Determinism.** Every output (edits, geometry, query results, blobs) is bit-identical on x86_64, aarch64
   and wasm32: M1 rules apply (`libm` only for transcendentals, `float::{min, max, …}`, `canon` before
   serialization, no `usize` in output). Containers are `BTreeMap`/`BTreeSet`; rstar hits are sorted by
   `(z, id)`; ids from `IdSource` are drawn in documented order; booleans use `i_overlay`'s integer API on
   the 1/16 px grid; fill uses fixed cells, never zoom.
2. **Absolute LWW patches.** `Update` carries the absolute new value of each set `Field`, never a delta.
   Transforms are emitted once at gesture end. Applying the same `Update` twice equals applying it once.
3. **Tombstones.** Items are never hard-removed. `Delete` sets `deleted`; `Update { deleted: Some(false) }`
   restores. Updates on tombstones are accepted (they keep LWW state).
4. **Inverse edits.** `Scene::invert(e)` computed before `apply(e)` undoes `e` exactly:
   `apply(e); apply(invert(e))` restores every field `e` wrote, bitwise.
5. **Order.** All id lists returned by core are sorted by `(z, id)` ascending (or by id where documented);
   paint order is `(band, z, id)`.
6. **Immutable data.** Stroke samples/seed/trim, erase items, text sources and item kinds never change after
   `Add`; only `Field`s do.
7. **Families.** A trimmed piece's `Trim::origin` is a root stroke id. Effective visibility of a live family
   member = `own ∩ ⋂ family_visible(other live members)`, folded in id order, recomputed whenever a member is
   added, deleted or restored.
8. **Masks follow targets.** Erase paths live in the target's local frame; target transform changes move them;
   a dead target makes its masks inert (not deleted).
9. **No panics on any input.** Invalid edits return `EditError` with the scene unchanged; decoders return
   `CodecError`; tools return empty `Vec`s for degenerate input.
10. **Undo grain.** One pen-down → up gesture = one step; undo only touches fields whose current value is
    bitwise what this device wrote; never emits a no-op step.

## Known limitations (accepted for M2)

- Two concurrent precise erases of the same **fill** keep only the later `Polygons` value (LWW).
- Undo staleness uses value equality, not op stamps (core has no op metadata).
- Fill regions wider than 4096 px return `OpenRegion`.
- Trimmed outline strokes keep `CONTEXT_SAMPLES` of context; extremely slow One Euro settling can still shift
  ink near a cut by sub-pixel amounts.

## Cross-slice dependencies

- a's `edit/proximity.rs` and `item/affine.rs` are used by b, c, d: slice a lands them first (small, early) and
  messages b, c, d.
- a's `Item::derive_geometry` calls b's `StrokeItem::{build_geometry, centreline}`, b's `EraseItem::page_mask`,
  d's `shape::shape_geometry`, c's `Polygon::mapped`.
- b, c, d, e read the scene through a's `Scene` API; scene-level tests in those slices run after a lands.
- d's `shape::resize::create_frame` uses a's `edit::transform::snap_angle`.
- e's codec reuses M1's `codec::stroke::{encode_params, decode_params, encode_samples, decode_samples}`.
